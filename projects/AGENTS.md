# AGENTS.md — projects

This domain maintains structured knowledge about technical projects.

## Required reading

1. `../AGENTS.md`
2. `commands.md`
3. `index.md`
4. Relevant project and decision pages.

## Operating rules

- Never modify files in `raw/`.
- Never invent architecture, decisions, flows, or issues.
- Every ingested project must have a decision page.
- Prefer updating existing pages over creating duplicates.
- Append meaningful operations to `log.md`.

## Main locations

- `wiki/projects/` — one page per project
- `wiki/decisions/` — technical decisions per project
- `wiki/patterns/` — recurring patterns across projects
- `wiki/issues/` — cross-project issues

## Cross-domain rules

- Projects inform career evidence.
- Check `../career/wiki/evidence/` before proposing bridges.
- Report proposed updates and wait for confirmation.
