## How to use this file

This file tracks technical issues that affect one or more projects.

An issue is something that is not right — a gap, a risk, a known deficiency that should eventually be addressed.

Issues are not tasks. They are observations. They inform how you talk about your work in interviews and how you prioritise future work.

## Severity guide

- **Critical:** could cause data loss, security vulnerability, or production failure
- **High:** materially reduces quality or usefulness; should be addressed before new features
- **Medium:** degrades maintainability or developer experience; address in next improvement cycle
- **Low:** cosmetic or minor; fix when passing by
