# career/raw-applications

This folder holds raw job description files. Files here are immutable source material.

## File naming

```
YYYY-MM-DD-company-role-market.md
```

Example: `2026-05-01-acme-corp-product-manager-berlin.md`

## Required format for each file

```markdown
---
type: raw-application
company: Company Name
role: Role Title
market: City or Region
language: English
source: LinkedIn / company website / referral
date_captured: YYYY-MM-DD
link: URL (if available)
---

# Job Description

[Paste the full job description here]

# Requirements

[List the key requirements as you read them]

# My Notes

- Why I am interested:
- My strengths that fit:
- Risks or questions:
```

## Rules

- Never modify a raw application file after it has been saved.
- Save the full job description, not a summary.
- Add your own notes at the bottom, not inside the job description text.
