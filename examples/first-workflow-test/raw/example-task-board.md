# Example Task Board

This is a fictional source file created only to test the template workflow.

## Project idea

A small task board app with three columns.

- To Do
- In Progress
- Done

A task has a title, description, due date, and priority.

Tasks can move between columns.

## Main decision

The first version is frontend only.

The reason is to test the interaction model before adding persistent server storage.
