# Release v1.0.0 — Agent Ready Knowledge Brain

Release date: 2026-05-05

## Summary

This is the first stable release of Agent Ready Knowledge Brain as a reusable multi-agent Obsidian vault template.

The project is no longer just a Markdown vault structure. It now provides a complete operating model for using one Obsidian-based Knowledge Brain across Claude Code, Codex, ChatGPT Projects, Custom GPTs, Antigravity, Cursor, and repository-based agents.

The core idea is simple.

Different agents can enter through different files, but they must operate on the same Markdown source of truth.

## Included default domains

- `career/` for job search, applications, CVs, positioning, public assets, evidence, and tracker feedback.
- `projects/` for technical project knowledge, architecture, decisions, flows, issues, improvements, and patterns.
- `writing/` for drafts, essays, articles, public content, themes, voice rules, and publication preparation.
- `personal/` for diary, health, decisions, reviews, and private pointer-only signals.
- `_bridges/` for cross-domain synthesis.
- `_domain-template/` for creating new domains.

## Recommended setup

Start with:

1. `docs/getting-started.md`
2. `docs/agent-workflow.md`
3. `docs/privacy-model.md`
4. `docs/customising-the-template.md`
5. `docs/template-audit.md`

Do not add private data until you have reviewed the privacy model and confirmed that the repository is private.

## Known limitations

- This is a Markdown operating model, not an Obsidian plugin.
- ChatGPT workflows remain more manual unless repository access or file uploads are provided.
- Multi-agent use still requires discipline. Only one agent should modify the vault at a time.
- The template provides structure and rules, but it does not replace human review.
