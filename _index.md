# Knowledge Brain — Index

Unified navigation for all domains.

## Domains

| Domain | Purpose | Index |
|--------|---------|-------|
| `career/` | Job search, CV generation, professional positioning | [[career/index]] |
| `personal/` | Daily diary, health tracking, personal decisions | [[personal/index]] |
| `projects/` | Technical projects, architecture, development | [[projects/index]] |
| `writing/` | Articles, essays, drafts, public content | [[writing/index]] |
| `writing-memoir/` | Life episodes, biographical narrative (optional) | [[writing-memoir/index]] |

## Cross-Domain Layer

| Resource | Purpose |
|----------|---------|
| [[_bridges/README]] | Cross-domain synthesis pages |

| [[_bridges/writing-to-career/]] | Published work → professional positioning |
| [[_bridges/memoir-to-career/]] | Life episodes → career evidence (if writing-memoir is active) |

## System Rules

- `raw/` folders are immutable — never modify after first save
- `wiki/` folders contain all structured knowledge
- Agents never push changes automatically
- Review diffs before confirming any agent write operation
