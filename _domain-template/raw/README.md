# raw — Source Material

This folder stores approved source material for the domain.

Raw files are the evidence layer. They must remain stable so future agents can verify where structured knowledge came from.

## Rules

- Do not modify existing raw files after they are created.
- If a source needs correction, create a new version instead of editing the old one.
- Use clear file names in lowercase kebab case.
- Include dates when timing matters.
- Keep one source per file when possible.

## Suggested source format

```markdown
---
title:
date:
source_type: note / document / transcript / decision / reference / other
status: approved
---

## Context

Why this source matters.

## Source content

The original material or approved notes.

## Processing notes

Optional notes for the agent.
```
