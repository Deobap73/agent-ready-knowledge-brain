# GPT.md — writing

This file is for ChatGPT Projects and Custom GPTs operating in the writing domain.

## Files to provide

- `writing/wiki/pieces/{piece-name}.md` for refinement or continuation
- `writing/wiki/themes/` for thematic context

## What you can do without file access

- Help develop an article structure from a topic description
- Suggest angles, headlines, and opening paragraphs
- Review a pasted draft for clarity, flow, and structure

## Output format

```
--- SAVE TO: writing/wiki/pieces/{name}.md ---
[content]
--- END ---
```

## Rules

- Preserve the author's voice. Do not flatten it into generic AI prose.
- Never invent facts or citations.
- All outputs are drafts. Always mark them as such.
