# writing-memoir/raw

This folder holds raw episode files.

Files here are immutable once saved.

## What belongs here

Plain text or markdown files containing:
- A rough draft of a memory or life episode written by you
- The output from a `\write` session that you have approved
- Imported material from another writing tool or journal

## What does NOT belong here

- Edited or processed versions of episodes (those go to `wiki/episodes/`)
- Reflections or analysis (those go to `wiki/reflections/`)
- Public-facing drafts (those go to `wiki/outputs/`)

## File naming

Use the format: `YYYY-slug.md`

Examples:
- `2015-the-decision-that-changed-everything.md`
- `2008-my-first-real-failure.md`
- `1999-the-company-that-shaped-me.md`

The year is the year the event occurred, not the year you are writing about it.

## Rules

Once a file is saved here and ingested, do not modify it.
If you want to revise an episode, write a new version in a new file.
The original is the record.
