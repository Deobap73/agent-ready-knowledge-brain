# writing-memoir/wiki/themes

This folder holds theme pages — one per recurring theme across the memoir.

## What is a theme

A theme is a pattern of behaviour, belief, or circumstance that appears in multiple episodes.

Themes are not topics. "Leadership" is not a theme. "Leading without being in charge" is a theme — because it describes something specific that keeps appearing.

## File naming

`{theme-slug}.md`

Examples:
- `leadership-without-authority.md`
- `building-on-other-peoples-land.md`
- `change-in-resistant-systems.md`

## Required sections

1. **Definition** — what this theme means specifically for this person
2. **Episodes where it appears** — table with episode name and how the theme manifests
3. **How it evolves** — does the behaviour or pattern change across episodes?
4. **Career relevance** — does this theme support any professional positioning claim?

## How agents use this folder

When ingesting an episode, agents update the relevant theme pages.

When using `\query`, agents read theme pages to find relevant episodes.
