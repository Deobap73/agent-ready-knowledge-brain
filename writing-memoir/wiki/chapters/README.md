# writing-memoir/wiki/chapters

This folder holds the chapter structure of the memoir.

## Purpose

Chapters group episodes for navigation and interview preparation.

The chapter structure serves three uses:

1. **Interview preparation** — instead of loading all episodes, load one chapter relevant to the question type
2. **Career evidence by period** — career-relevant episodes cluster in specific phases; chapters make it fast to load only the relevant period
3. **Narrative coherence** — when writing new episodes, the chapter structure shows which phase they belong to

## How to define chapters

Chapters are not arbitrary containers. They should reflect meaningful periods or arcs in your life story.

Examples:
- Early Life and Formation (childhood, education, early career)
- Professional Awakening (first real work, first leadership)
- Peak and Setback (best outcomes, hardest lessons)
- Transition and Reinvention (career change, new country, new context)

## This README IS the chapter map

Rather than creating individual chapter files, use this README as the chapter map.

For each chapter, document:
- Chapter name and period
- Episodes it contains
- Narrative arc (what this chapter is about as a story)
- Career relevance (which interview questions this chapter answers)

## Rule

Do not create individual chapter files unless the chapter is long enough to need its own navigation.
Use this README as the navigation layer.
