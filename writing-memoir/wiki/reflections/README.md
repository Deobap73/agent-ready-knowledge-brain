# writing-memoir/wiki/reflections

This folder holds analytical reflection pages — one per episode.

## Purpose

A reflection is not a summary of the episode. It is an analysis of what the episode means.

The episode is the raw event. The reflection is the question: what does this event reveal about who you are and what you have learned?

## File naming

`YYYY-episode-slug-reflection.md`

## Required sections

1. **What this moment means** — 1 to 3 sentences on the significance
2. **Patterns** — what recurring behaviours or capabilities this episode demonstrates
3. **Career relevance** — whether this episode supports any professional claims

## How agents use this folder

When extracting career material with `\extract`, agents read the reflection alongside the episode to identify what professional claims the story supports.

When running `\review`, agents flag episodes that do not have a corresponding reflection.
