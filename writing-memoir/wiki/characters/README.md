# writing-memoir/wiki/characters

This folder holds character pages — one per significant person in the memoir.

## What belongs here

A character page exists for anyone who appears in more than one episode and has a role in the narrative arc.

Not every name mentioned in an episode needs a character page.

## File naming

`{character-slug}.md`

Examples:
- `the-mentor.md`
- `the-father.md`
- `the-colleague.md`

Use descriptive labels rather than real names unless you are comfortable having those names in your vault.

## Required sections

1. **Real role** — who this person is in real life
2. **Function in the memoir** — what role they play in the narrative
3. **Episodes** — table of episodes where they appear and their role in each
4. **How the relationship evolves** — does it change across episodes?
5. **What they represent** — the symbolic or structural meaning of this character

## How agents use this folder

Before writing a new episode, agents read character pages to ensure consistency — same name, same relationship, same characterisation.

When ingesting, agents update character pages when a character appears in a new episode.
